# Dice Roller

A simple command-line utility to roll dice.

## Usage

```bash
python main.py 2 --sides 6
```

Rolls two six-sided dice.

## Features
- Roll any number of dice
- Specify number of sides
- Simple and easy to use.

## Installation

No installation is required; just run the script.

```bash
python dice_roller/main.py 3
```
